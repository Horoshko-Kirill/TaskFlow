# TaskFlow

TaskFlow — простое клиент-серверное приложение для управления проектами и задачами.

Приложение позволяет создавать проекты, добавлять участников, создавать и распределять задачи между пользователями, изменять статус задач с помощью Kanban-доски, оставлять комментарии и просматривать собственные задачи.

## Возможности

* создание, просмотр, редактирование и удаление проектов;
* добавление и удаление участников проекта;
* создание, просмотр, редактирование и удаление задач;
* назначение задач участникам проекта;
* Kanban-доска со статусами:
  * Todo;
  * In Progress;
  * Done;
* изменение статуса задачи с помощью drag-and-drop;
* фильтрация задач текущего пользователя;
* отдельная страница «My Tasks»;
* фильтрация задач по приоритету;
* создание, редактирование и удаление комментариев;
* хранение данных в PostgreSQL;
* автоматическое применение миграций при запуске Docker Compose.

* FluentValidation;

### Frontend

* Angular 20;

* HTML;

### Инфраструктура

* Docker;
* Docker Compose;
* Nginx;
* PostgreSQL;
* отдельный контейнер для применения миграций.

### Backend

Backend разделён на несколько проектов:

* `TaskFlow.Domain` — доменные сущности и перечисления;
* `TaskFlow.Application` — интерфейсы, DTO, сервисы и бизнес-логика;
* `TaskFlow.Infrastructure` — работа с PostgreSQL и реализация репозиториев;
* `TaskFlow.API` — HTTP REST API;
* `TaskFlow.Migrations` — отдельное приложение для применения миграций базы данных.

### Frontend

Angular-приложение находится в:

```text
frontend/taskflow-web
```

Frontend взаимодействует с backend посредством HTTP REST API.

## Требования

Для запуска необходимы:

* Docker Desktop;
* Docker Compose.

Локально устанавливать .NET, Node.js, Angular CLI или PostgreSQL для запуска приложения не требуется.

## Настройка конфигурации

Перед первым запуском необходимо создать файл `.env` в корневой директории проекта.

Пример файла находится в:

```text
.env.example
```

Скопируйте его:

```text
.env.example → .env
```

Пример содержимого:

```env
POSTGRES_DB=taskflow
POSTGRES_USER=taskflow
POSTGRES_PASSWORD=taskflow_password
```

При необходимости значения можно изменить.

## Запуск приложения

Перейдите в корневую директорию проекта.

После создания `.env` выполните:

```cmd
docker compose up --build -d
```

Docker Compose создаст и запустит следующие сервисы:

```text
TaskFlow.db
TaskFlow.migrations
TaskFlow.api
TaskFlow.frontend
```

Проверить состояние контейнеров можно командой:

```cmd
docker compose ps
```

Все основные сервисы должны находиться в состоянии `running` или `exited` для одноразового контейнера миграций.

Контейнер `TaskFlow.migrations` выполняет миграции базы данных и после успешного завершения может находиться в состоянии `Exited (0)`. Это является нормальным поведением.
